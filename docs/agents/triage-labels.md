# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer evaluation |
| needs-info | needs-info | Awaiting information or decisions |
| ready-for-agent | ready-for-agent | Fully specified for agent work |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping repository-wide. Do not create a backend-specific mapping.

Before creating labels, inspect existing GitHub labels and create only missing
names. Preserve existing labels, colors, and descriptions.

Labels do not grant permission to bypass explicit user approval requirements.
